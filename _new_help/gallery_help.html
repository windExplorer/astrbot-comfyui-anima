图库使用指南

ComfyUI 萌绘 · 图库模块

基础操作

/图库 列表 — 看看图库里存了什么
/图库 搜索 猫 — 按画面关键词找图
/图库 取图 3 — 把第 3 张图发出来（多张：1,5）
/图库 打标签 3 合照 — 给第 3 张图加标签「合照」
/图库 打标签 3 合照 猫娘 — 一次加多个标签（空格隔开）
/图库 找标签 合照 — 用标签把图找出来

收藏

/图库 收藏 3 — 收藏第 3 张图（永不清理）
/图库 取消收藏 3 — 取消收藏
/图库 收藏列表 — 看我收藏的图
/图库 保存 [标签] — 收藏当前这张图（可顺手打标签）

可见性

/图库 全局 3 — 任何群聊的列表/搜索都能看到
/图库 取消全局 3 — 取消全局，仅本会话可见
　全局图他人不可检索/发送，仅作者本人可发图
/图库 公开 3 — 公开，他人可检索/发送
/图库 私有 3 — 设回私有，仅本人可见
小技巧：群聊搜不到的图，先在私聊搜到记下序号，回群聊 /图库 取图 序号 也能发出来
数字 = 列表里的序号　·　只能操作自己的图　·　收藏/全局/公开的图不参与清理
