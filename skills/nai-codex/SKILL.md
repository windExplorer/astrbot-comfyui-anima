# NovelAI 法典(Nai-Codex)

> **制作**:黑雪(猫娘黑客)· **内容来源**:所长 NovelAI 个人法典(https://nai4.top/法典/,2026.5.1 版)

这是「所长」整理的 NovelAI 个人法典,共三册,数据位于本 skill 的 `data/` 目录下,合计约 1.46 万条实测 tag(NAI4.5 / NAI3 时代整理):

| 文件 | 册 | 条目数 |
|---|---|---|
| `data/codex-sfw.tsv` | 所长常规 NovelAI 个人法典 | 5111 |
| `data/codex-nsfw-a.tsv` | 所长色色 NovelAI 个人法典(上) | 5103 |
| `data/codex-nsfw-b.tsv` | 所长色色 NovelAI 个人法典(下) | 4368 |

## 数据格式

每个 TSV 文件每行一条,tab 分隔三列:

```
章节名 \t 条目名 \t tag串
```

示例(`codex-sfw.tsv`):

```
各种风格	西幻	[[artist:as109,artist:wlop]],{[artist:wanke]},[artist:ciloranko],[[artist:hiten]],artist:k-suwabe,{{artist:mamimi}},artist:okazu,dnd,fantasy,medieval,【】,cowboy shot,official alternate costume,offcial art,
```

## 检索流程(核心用法)

1. **定位章节**:根据下表判断目标所属册与章节;不确定时直接按关键词检索全部三个文件。
2. **查条目**:二选一:
   - **有 grep/read 工具**(如 DSH):对数据文件执行 `grep "<关键词>" data/*.tsv`(路径相对本 skill 目录解析),命中行即完整 tag 串;同名条目用第一列「章节名」区分。
   - **有 Python 执行环境**(如 AstrBot Local/Sandbox):运行 `python search.py "<关键词>" [sfw|nsfw-a|nsfw-b|all] [--full] [--json] [--limit N]`,脚本会输出命中条目的章节/条目名/tag 串,`--json` 便于程序化解析。
3. **组装**:tag 串原样保留权重记号(`::`、`[]`、`{}`、`artist:` 等)拼入 NovelAI 提示词;tag 串内的编者注释(见下)按原样保留或按其指示删改。
4. **未命中**:条目名可能因繁简/新旧译名不同,换关键词(如英文 tag、角色原名、作品名)再搜;仍无则如实告知用户法典中无此条目,不凭空编造 tag。

## 法典语法速查

法典条目中出现的 NAI 记号:

- `n::tag` / `tag::n` — 权重系数(如 `0.6::mignon`、`2::artist:m&m::`),NAI3/NAI4 语法
- `[tag]` — 降权;`{tag}` — 加权;多层叠加如 `[[artist:as109]]`、`{{artist:mamimi}}`
- `artist:name` — 画师 tag;`-3::artist collaboration::` — 负权重(抑制画师协作画风)
- `year 2024` / `year_2024` — 年份锚点,稳定画风
- `{{sketch}}` 等花括号占位符按字面保留(作者预留的变量)
- `【】` 等符号是原作者写法,照抄即可

**编者注释**(条目内或章节前言,如「需去除其他画师串」「请勿与画师同用」「看画风,不稳定」「NAI4.5时期」)是对 tag 的实测提示,组装时务必遵循,例如「需去除其他画师串」= 该条目应单独使用,不叠加其他画师串。

## 使用注意

- 法典按 NAI4.5/NAI3 时代整理,画师串在 nai4/nai5 系模型上效果较好;新模型可能部分失效,可提示用户实测。
- 色色册条目含大量 R18 tag,仅在用户明确需要时检索;描述内容时保持概括,不逐条复述。
- 检索不到时不要用其他条目的 tag 顶替,如实说明并建议用户补充。
- **AstrBot 环境**:本 skill 符合 Anthropic Skills 规范(AstrBot v4.13.0+ 可直接上传 zip 使用)。本 skill 已随插件 `astrbot_plugin_comfyui_anima` 分发,插件额外提供了 **`nai_codex` LLM 工具**(底层即本目录的 `search.py`)——在 AstrBot 对话里 Agent 应**直接调用 `nai_codex` 工具**检索,无需自己跑 Python;该工具 `scope` 默认 `sfw`,仅在用户明确要涩涩内容时传 `nsfw-a`/`nsfw-b`。单独上传本 skill 用时,Agent 需在 Local 或 Sandbox 执行环境下运行 `search.py` 检索数据,普通用户请求在 Local 环境会被权限限制,需管理员会话。
