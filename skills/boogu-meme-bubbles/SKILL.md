# 表情包制作大师（anima 绘图 + boogu 加字）

## 一、核心：一个表情包工作流 = 两段提示词串联

做一张表情包，底层是**同一个 ComfyUI 工作流**，按固定顺序串起两段提示词：

1. **第一段 prompt —— anima 绘制提示词**：交给 ComfyUI/anima 画出角色、表情、动作、场景。
   - 直出表情包：这一段是「文生图」，anima 按你的画面描述画出图。
   - 图生表情包：这一段是「图生图」，你额外给一张参考图，anima 在它基础上生成。
2. **第二段 prompt —— boogu 加气泡/文字提示词**：把第一段画好的图交给 boogu，
   用一段**中文自然语言**指令告诉它「在哪加什么气泡、写什么台词、要不要底部旁白」。

一句话：**第一段决定「画了什么」，第二段决定「图上说了什么」。两段都在同一个工作流里，不是两个独立步骤。**

## 二、直出 vs 图生（只是第一段怎么出图）

| 场景 | 工具 | 第一段（anima） | 第二段（boogu 加字） |
| --- | --- | --- | --- |
| 用户没给图，从零画 | `comfyui_comic` | 文生图（按画面描述画） | 加气泡/台词（与图生完全相同） |
| 用户给了参考图 | `comfyui_meme_img` | 图生图（参考图 + 提示词） | 加气泡/台词（与直出完全相同） |
| 普通生图，画面不要字 | `comfyui_draw` | 文生图 | 无 |

→ 直出和图生**共用同一套第二段 boogu 加字逻辑**，区别仅在第一段是文生图还是图生图。

## 三、两种用法下你怎么填这两段

- **指令直填（`/表情包`）**：语法就是把两段显式分开——
  `/表情包 第一段画面描述::第二段气泡台词[::第二段底部旁白]`
  例：`/表情包 一只猫炸毛瞪眼::你干嘛！！::这就是好奇心`
  `::` 前 = anima 绘图提示词（第一段）；第一个 `::` 后 = boogu 气泡台词（第二段）；
  第二个 `::` 后 = boogu 底部旁白（第二段，可省略，见第四节「旁白默认不加」）。
- **AI 对话（工具）**：你只需把用户的「画面想法」传给 `comfyui_comic` / `comfyui_meme_img` 的 `prompt`，
  插件内部会用内部 LLM 把它展开成「anima 绘图提示词（第一段）+ boogu 加字提示词（第二段）」两段：
  气泡台词由内部 LLM 按情绪自动写，你可以用画面描述里的措辞影响它
  （如「大喊『退退退』」「用爆炸气泡」「粉边小字OS」「不要旁白」）。

## 四、第二段 boogu 提示词怎么写（气泡/文字样式目录）

第二段是给 boogu 的**自然语言指令**，内部 LLM 会按情绪从下面选样式（你在上层只需把样式要求写进画面想法）：

- **云朵气泡**：可爱、温柔、日常、轻松对话。蓬松白气泡 + 小尖角指嘴，圆润卡通体。
- **圆角对话气泡**：普通说话、陈述、解释、提醒。白圆角矩形 + 小尾巴。
- **思考气泡**：内心OS、悄悄话、犹豫、自言自语。由小到大的圆形气泡串，手写体。
- **爆炸气泡**：大喊、震惊、激动、吐槽爆发。星形/爆炸彩色气泡，粗黑体，夸张外扩。
- **尖角气泡**：怒气、急促、电竞感、质问。带棱角/锯齿边缘的白气泡，粗体。
- **底部字幕条**：【偶用】旁白、吐槽、真相总结、说明。底部白色圆角横条，粗描边。⚠️ 见下，默认不加。
- **无气泡白字黑边**：通用梗图、大字标题、上/下居中配字。经典表情包大字（白填充 + 黑粗描边）。
- **无气泡直接压字**：把字压在画面安静区、不挡主体。圆润卡通体 + 白细描边保可读。
- **放射爆裂大字**：拟声词（咚/啪/汪）、极度强调、冲击感。放射状炸开粗体 + 速度线，橙红配色。

★ 样式细节要会变化（别永远深棕/黑描边 + 超大字）：
- **边框/描边颜色**：可跟随角色发色或情绪色（愤怒→红、害羞→粉、平静→墨色/原色），不必固定深棕或黑。
- **线条粗细**：大喊/震惊→粗，温柔/悄悄话/内心OS→细。
- **字号**：强调/标题/大喊→大，轻语气/内心OS/日常→中等或偏小，不固定一律超大。

★ 用户若明确指定样式（「用爆炸气泡」「不要气泡」「底部字幕条」「经典白字黑边」「粉边」「小字」），优先满足。

## 五、旁白（底部字幕条）原则

**默认【不加】旁白。** 绝大多数表情包只有气泡台词，没有底部旁白。只有当：
- 内容明显是吐槽 / 真相总结 / 画龙点睛；或
- 用户明确要「字幕 / 旁白 / 底部加一句」
才使用「底部字幕条」样式。不要为了凑而自动补旁白。

## 六、boogu 自然语言写法与铁律

boogu 是**指令式图生图模型**：节点里的一段中文自然语言就是全部指令，**不认识任何字段名**（`bubble=` / `bottom=` 等一律无效），只认自然语言。

写第二段 boogu 指令要覆盖：位置、形状/底色、文字内容、边框颜色、线条粗细、字体（圆润卡通体 / 粗黑体 / 手写体）、字号。
文字务必短：**气泡 ≤8 字、底部 ≤6 字**；长文 / 小字 boogu 极易错字缺字，宁短勿长。

限定词速查：
- 「不要气泡 / 不加气泡」→ 用「无气泡白字黑边」或「无气泡直接压字」。
- 「内心OS / 悄悄话」→ 思考气泡。
- 「拟声 / 冲击」→ 放射爆裂大字。
- 「底部字幕 / 旁白」→ 底部字幕条（且符合第五节才加）。

## 七、和你（上层 LLM）相关的要点

1. 直出用 `comfyui_comic`、图生用 `comfyui_meme_img`；二者都是「第一段 anima 绘图 + 第二段 boogu 加字」同一工作流。
2. 你只传「画面想法」给工具的 `prompt`；气泡台词由插件内部按情绪自动写，样式要求写进画面想法即可（如「用爆炸气泡大喊」「粉边小字OS」）。
3. 旁白默认不加；用户要才加。
4. 不要手填文字槽位、不要输出 `bubble=` 之类字段名——那不是 boogu 的格式；第二段只认自然语言。
