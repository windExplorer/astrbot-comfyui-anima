# 表情包制作大师（anima 绘图 + boogu 加字）

## 一、核心：两种表情包，流程不同（重点）

- **直出表情包（`comfyui_comic`）**：一个 ComfyUI 工作流里串起**两段**提示词：
  1. **第一段 prompt —— anima 绘制提示词**：anima 按画面描述文生图，画出角色/表情/场景。
  2. **第二段 prompt —— boogu 加气泡/文字提示词**：把画好的图交给 boogu，用自然语言指令加气泡/台词/旁白。
- **图生表情包（`comfyui_meme_img`）**：**专门的 boogu 工作流，没有第一段（anima 绘图）**。
  只需**一张参考图 + 一个提示词**：
  - 那一个提示词就是 **boogu 指令**：boogu 根据用户给的描述**修饰这张图**（改表情 / 加元素等）
    **并加气泡和文字**。风格来自参考图本身，不是 anima 画的。

一句话：直出是「anima 画 + boogu 加字」两段；图生是「boogu 直接改图 + 加字」一段（只有 boogu，无 anima）。

## 二、工具路由

| 场景 | 工具 | 流程 |
| --- | --- | --- |
| 用户没给图，从零画 | `comfyui_comic` | 第一段 anima 文生图 + 第二段 boogu 加字（两段） |
| 用户给了参考图 | `comfyui_meme_img` | 仅 boogu 一段：参考图 + 一个 boogu 指令（改图 + 加字），**无 anima** |
| 普通生图，不要字 | `comfyui_draw` | 文生图 |

## 三、两种用法下你怎么填

- **指令直填（`/表情包`）**：这是**直出**语法，把两段显式分开——
  `/表情包 第一段画面描述::第二段气泡台词[::第二段底部旁白]`
  例：`/表情包 一只猫炸毛瞪眼::你干嘛！！::这就是好奇心`
  `::` 前 = anima 绘制提示词（第一段）；第一个 `::` 后 = boogu 气泡台词（第二段）；
  第二个 `::` 后 = boogu 底部旁白（第二段，可省略，见第七节「旁白默认不加」）。
- **AI 对话（工具）**：
  - `comfyui_comic`（直出）：传 `prompt` = 画面想法，内部展开为「anima 绘图提示词（第一段）+ boogu 加字提示词（第二段）」两段；
    气泡台词由内部 LLM 按情绪自动写；想让图好看就把**风格/表情/构图**写进 `prompt`（见第四节）。
  - `comfyui_meme_img`（图生）：附一张参考图，传 `prompt` = **boogu 指令**（怎么改这张图、加什么气泡/文字）。
    **这里没有 anima 绘制，`prompt` 直接是给 boogu 的自然语言描述，不是「画面描述」**；想改表情/加元素/加字都写在这条指令里。

## 四、直出的第一段 prompt（anima 绘图）怎么画才好看的表情包

⚠️ 本节只适用于**直出 `comfyui_comic`**（有 anima 绘图段）。图生没有 anima 段，风格来自参考图。

第一段是 anima 画「图」的提示词，决定表情包底子好不好看。内部 LLM 会把你传给工具的 `prompt`（中文想法）
翻成详细英文 Danbooru 标签写进第一段；**你在 `prompt` 里多给「风格 / 表情 / 构图」词即可生效**。

做表情包和做普通图不同，要点是「字能读、脸能懂」：

- **表情是灵魂**：让用户情绪夸张（瞪大眼、张嘴、脸红、流泪、炸毛、扶额），比精致背景重要得多。
- **构图留白**：角色建议上半身 / 大头特写、居中或偏一侧，四周留空给气泡；别铺满整图，否则气泡没处放、字也挤。
- **背景简洁**：用 `simple background` / `plain background` / `solid color` / `white background`，
  避免复杂场景——白字气泡在花背景上会糊、读不清。
- **风格取向**：干净利落、色块明确的动漫赛璐璐风（cel shading）最稳；避免写实、厚涂、过暗、噪点重的风格（字读不清）。可加 `clean lineart`、`flat color`。
- **画质词**：`masterpiece, best quality, high quality` 照常带。
- 例：用户想法「一只猫炸毛瞪大眼、夸张震惊」→ 内部 LLM 翻成
  `masterpiece, best quality, 1cat, surprised, wide eyes, open mouth, upper body, simple white background, cel shading, clean lineart...`。

## 五、LoRA 怎么用

- LoRA 主要是**直出 `comfyui_comic` 的 anima 绘制段**用的（给绘图加风格 / 角色）。
  **图生 `comfyui_meme_img` 没有 anima 段**，风格来自参考图本身，一般无需画风类 LoRA。
- 表情包功能（special_features 的 `meme_text`）通常已在配置里配好**默认 LoRA 与默认负向词**
  （`default_lora` / `default_negative`），直出会自动带上，**一般不必额外加 LoRA**。
- 当用户要**特定画风 / 角色 / 人物**时，才需要加：
  1. 先调 `comfyui_loras` 查真实可用的 LoRA（可按 keyword / category 过滤，角色类传 `category=角色`），
     **不要凭记忆或猜测名字**；
  2. 把名称填进工具的 `loras` 参数，支持 `"名称"` 或 `"名称:权重"`（如 `catgirl:0.8` 弱化、`1.2` 增强）；
     没给权重用默认。
  3. 有匹配**角色 LoRA** 就填它，且**不要再**用 danbooru 标签重复描述该角色外形（会冲突）。
- 只有确认没有任何匹配 LoRA、或用户明确不要 LoRA 时，`loras` 才留空（用功能默认 LoRA）。

## 六、boogu 提示词怎么写（气泡/文字样式目录）

⚠️ 这一节同时适用于：**直出的第二段** 和 **图生的唯一一段**（图生时这段指令还负责「修饰图」）。

boogu 指令是**自然语言**，内部 LLM 会按情绪从下面选样式（你在上层只需把样式要求写进描述）：

- **云朵气泡**：可爱、温柔、日常、轻松对话。蓬松气泡 + 小尖角指嘴；底色半透明白/淡彩，描边跟随发色/情绪。
- **圆角对话气泡**：普通说话、陈述、解释、提醒。圆角矩形 + 小尾巴；半透明白底，描边跟随情绪。
- **思考气泡**：内心OS、悄悄话、犹豫、自言自语。由小到大的圆形气泡串，手写体，可半透明。
- **爆炸气泡**：大喊、震惊、激动、吐槽爆发。星形/爆炸彩泡（橙红/亮黄），粗黑体，夸张外扩。
- **尖角气泡**：怒气、急促、电竞感、质问。棱角/锯齿边缘，描边可用怒气红，半透明白底。
- **底部字幕条**：【默认不加】仅旁白/吐槽/真相总结/用户明确要字幕才用。底部半透明横条。
- **无气泡白字黑边**：通用梗图、大字标题、上/下居中配字。白填充 + 黑粗描边（克制，不盲目超大）。
- **无气泡直接压字**：把字压在画面安静区、不挡主体。圆润卡通体 + 白细描边，可半透明叠加。
- **放射爆裂大字**：拟声词（咚/啪/汪）、极度强调、冲击感。放射状炸开粗体 + 速度线，橙红配色。

★ 样式细节必须多变（别一尘不变）：
- **字号随字数自适应、整体偏小、宁小勿大**：字数≤4 可稍大；5-8 字中等；>8 字缩小并自动换行；
  文字务必在气泡/图形内【留内边距、绝不溢出边缘】（溢出是严重错误），不要动不动就「超大」。
- **边框/描边颜色**：跟随角色发色或情绪色（愤怒→红、害羞→粉、平静→墨色/原色），不要次次深棕或黑。
- **气泡底色**：可用【半透明白 / 淡彩色半透明】，或仅描边无填充（透明背景）；不要永远纯白实心。
- **线条粗细**：大喊/震惊→粗，温柔/悄悄话/内心OS→细。

★ 用户若明确指定样式（「用爆炸气泡」「不要气泡」「底部字幕条」「经典白字黑边」「粉边」「小字」），优先满足。

## 七、旁白（底部字幕条）原则

**默认【不加】旁白。** 绝大多数表情包只有气泡台词，没有底部旁白。只有当：
- 内容明显是吐槽 / 真相总结 / 画龙点睛；或
- 用户明确要「字幕 / 旁白 / 底部加一句」
才使用「底部字幕条」样式。不要为了凑而自动补旁白。

⚠️ 实现层已保证：只要走「漫画/带字工作流」，插件会**强制生成 boogu 指令并覆盖工作流节点里写死的默认提示词**——
所以即便你的 ComfyUI 工作流自带了默认字幕/超大字，默认也不会出现；只有上述两种情况才加底部字幕。

## 八、boogu 自然语言写法与铁律

boogu 是**指令式图生图模型**：节点里的一段中文自然语言就是全部指令，**不认识任何字段名**（`bubble=` / `bottom=` 等一律无效），只认自然语言。
（图生时，这段指令还要描述「怎么修饰参考图」，同样用自然语言。）

写 boogu 指令要覆盖：位置、形状/底色、文字内容、边框颜色、线条粗细、字体（圆润卡通体 / 粗黑体 / 手写体）、字号。
文字务必短：**气泡 ≤8 字、底部 ≤6 字**；长文 / 小字 boogu 极易错字缺字，宁短勿长。

★ **上层 LLM 绝对禁止**：在 `prompt`（段1 / anima 绘图提示词）里写 `text: 有点困了` / `Text: I'm a bit tired` / `气泡: xxx` / `bubble: xxx` 这类**字段**，也不要写 `cloud bubble` / `speech bubble` / `粉边` 等 boogu 形状描述。这些会被当成绘图标签塞进段1，让 anima 去画云朵气泡（画错），而且**根本不会进到气泡**。气泡文字由插件自动生成（按情绪/你的自然语言风格要求）；你若想指定，用自然语言描述「想要什么风格的气泡」即可，**不要写死文字内容**。插件已对段1 做兜底清理（自动剥离上述字段与 boogu 形状描述、并把字段里的文字转交槽位2），但请别再这么写。

限定词速查：
- 「不要气泡 / 不加气泡」→ 用「无气泡白字黑边」或「无气泡直接压字」。
- 「内心OS / 悄悄话」→ 思考气泡。
- 「拟声 / 冲击」→ 放射爆裂大字。
- 「底部字幕 / 旁白」→ 底部字幕条（且符合第七节才加）。

## 九、和你（上层 LLM）相关的要点

1. **直出 `comfyui_comic`**：一个工作流两段——第一段 anima 绘图 + 第二段 boogu 加字。
2. **图生 `comfyui_meme_img`**：只有 boogu 一段，一张参考图 + 一个 boogu 指令（改图 + 加字），**没有 anima 段**；`prompt` 直接是给 boogu 的描述。
3. 直出时你只传「画面想法」给 `prompt`；想让图好看就把**风格/表情/构图**写进 `prompt`，气泡台词由插件内部按情绪自动写、样式要求也写进 `prompt`（如「用爆炸气泡大喊」「粉边小字OS」）。
4. 图生时 `prompt` = 怎么改图 + 加什么字的 boogu 指令；LoRA 一般不用（无 anima 段）。
5. 要特定画风/角色（直出）：先 `comfyui_loras` 查，再把名称填 `loras`；功能默认 LoRA 已自动带，通常不用额外加。
6. 旁白默认不加；用户要才加。
7. 不要手填文字槽位、不要输出 `bubble=` / `text:` 之类字段名——那不是 boogu 的格式；第二段/图生段只认自然语言。`prompt`（段1/anima 绘图）里也**不要写** `text: 有点困了`、`cloud bubble`、`粉边` 这类字段或 boogu 描述（见第八节）。
8. 用户若在**问问题 / 评论**上一张图（如「咋没有文字了」「为啥没字」「这图好丑」），那是闲聊不是出图指令——在聊天里回答即可，**不要**把这句话当气泡文字去做新表情。只有用户明确想要一张带字表情包时才出图，且气泡写「角色想说的话 / 角色情绪」，而不是把用户的元评论原话写进去。
